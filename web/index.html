Epson Waste Ink Reset

Forbind en understøttet Epson-printer direkte med USB. Siden finder printermodellen i den lokale database og kan nulstille dens waste ink counter via WebUSB.

Kræver Chrome eller Chromium og HTTPS.

Vigtigt: Udfør kun reset efter fysisk service eller tømning af printerens waste ink pad/opsamling.
Klar. Tilslut printeren med USB og klik “Find Epson-printer”.
